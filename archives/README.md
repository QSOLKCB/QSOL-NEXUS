# NEXUS Archives

This directory preserves superseded NEXUS work for reference, idea mining, provenance, and future comparison.

Archived material is **not** the active NEXUS 2.x architecture unless a later document explicitly re-adopts a concept.

## v1.0.0

`v1.0.0/` is a snapshot of the previous browser-oriented NEXUS workbench as it existed immediately before the 2.x architecture transition.

The archive is intentionally kept as ordinary source files rather than rewritten summaries so future development can inspect the actual earlier design.

NEXUS 1.0 focused on:

- deterministic browser laboratories;
- scientific sonification;
- canonical experiment artifacts;
- replay and lineage;
- claim boundaries;
- offline/local browser execution.

NEXUS 2.x keeps useful ideas from that work while changing the primary architecture to a CLI/TUI-first, model-independent persistent world and AI Council.
