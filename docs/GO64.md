# GO64 — Secret Alias Mode

`/GO64` is a hidden operator-shell easter egg for the Rust TUI.

It is **not** a NEXUS World Mode, does not create a new geometry region, and does not change the Council protocol.

> **The terminal can cosplay as 1982. The substrate cannot.**

The current NEXUS room, World Mode, evidence set, Council roster, vote weights, geometry and world state remain untouched underneath the temporary text-mode overlay.

## Entering

The command is intentionally absent from ordinary `/help` and slash-command completion:

```text
/GO64

ARE YOU SURE?
YES
```

The confirmation is local to the TUI. Secret-bearing text still passes through the ordinary NEXUS scrub-preview boundary before it reaches local history or scrollback.

The initial screen is an original Commodore-inspired text interface:

```text
**** COMMODORE NEXUS/64 ****
 38911 COGNITIVE BYTES FREE

LOAD "$",8        DIRECTORY
LOAD "*",8,1      NEXUS/64 RETRO DEMO
LOAD "*",9,1      DR. S.BAITSO 2026 TEXT TRIBUTE
LIST               HELP
SYS 64738          SOFT RESET THIS ALIAS SESSION

READY.
```

There are no real disk waits. Decorative loading text never sleeps or deliberately slows the operator down.

## Device 8 — NEXUS/64 Retro Demo

```text
LOAD "*",8,1
```

launches a deterministic text-only demoscene-inspired program. It borrows the spirit of C64 intros and QSOLKCB/HERESY's FORCEOS '38 without requiring graphics, SID emulation, ANSI colour, a browser, or an emulator.

Its lesson is deliberately **not** "old technology is always better":

```text
NEWER != BETTER.
OLDER != BETTER.
MEASURE IT.
```

The demo focuses on architectural properties that old constrained systems made difficult to hide:

- resource budgets force tradeoffs into the open;
- one-file/offline systems can have extremely small deployment and failure surfaces;
- deterministic artifacts age well;
- inspectable text protocols are easy to archive and reason about;
- unnecessary network boundaries are optional failure modes.

It also states the counter-case explicitly: modern security, accessibility, scale and tooling matter when the problem requires them.

The intended lesson for human and machine participants is:

> **Use the smallest sufficient system for the actual contract. Newness and nostalgia are both poor substitutes for measurement.**

## Device 9 — DR. S.BAITSO 2026 text tribute

```text
LOAD "*",9,1
```

launches an original text-only meme-therapist tribute adapted from QSOLKCB/ETHICS. It reuses the project's own deterministic response-engine ideas and four modes:

```text
MODE THERAPY
MODE AGENT
MODE BENCHMARK
MODE DOOMSCROLL
```

The modes correspond to:

- Memetic Therapy;
- Agent Intervention;
- Benchmark Detox;
- Doomscroll Triage.

Useful local commands include:

```text
/diagnose
/ethics
/consultant
/back
/clear
/mute
/speak
```

Because GO64 is deliberately text-only, `/mute` and `/speak` are jokes rather than speech-device controls.

The tribute does **not** include Creative Labs code, speech recordings, artwork, or Masswerk page/script code. It is an original Rust/text implementation using QSOL-owned ETHICS material as its direct source.

It is entertainment and satire, not medical or mental-health care.

## The thirty-minute curse

GO64 has one monotonic session timer.

```text
00:00 -> classic text register
20:00 -> deterministic brainrot register
30:00 -> /grass unlocks
```

At twenty minutes, both the Retro tutor and Doctor S.BAITSO deliberately change style. The content boundary does not change; only the language register becomes terminally online.

Example:

```text
BRO SAID 'TASK COMPLETE' WITH NO COMMIT SHA 💀
RECEIPTS OR IT DID NOT HAPPEN, GANG.
```

At thirty minutes the TUI announces:

```text
*** 30:00 OUTDOOR DEVICE 0 IS NOW READY
*** TYPE /grass TO EXIT SECRET ALIAS MODE
```

Before 30:00, `/grass` reports the remaining lock time. `SYS 64738` can reset the fake C64 program state but deliberately **does not reset the thirty-minute timer**.

`/grass` is the normal way out of GO64 once the timer has matured. `/quit`, Ctrl-C and Ctrl-D remain emergency exits from NEXUS itself; the easter egg never traps the operator inside a process they cannot terminate.

On `/grass`, volatile GO64 reply state is discarded. Ordinary NEXUS terminal scrollback follows the normal TUI rules and is not falsely described as confidential or automatically erased.

## Claim boundary

GO64 is presentation and local deterministic entertainment.

It does not:

- alter `vote_weight`;
- alter Council consensus thresholds;
- change evidence or verification state;
- create a new World Mode or geometry region;
- change the current room;
- change protocol `nexus/0.8`;
- invoke remote services;
- execute shell commands;
- emulate a Commodore 64;
- claim old systems are universally superior.

The easter egg exists partly to demonstrate a NEXUS architectural point: the operator shell is replaceable and playful, while substrate semantics stay boring.
